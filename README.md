# Actividad de control de versiones

Este repositorio fue creado para practicar el uso de Git y GitHub.

El proyecto muestra como trabajar con ramas, realizar cambios pequeños y guardar cada avance con commits claros.

## Como revisar el proyecto

Primero se debe cambiar a la rama `feature-nombre`. Despues se pueden revisar los archivos y el historial de commits para confirmar los cambios realizados.
